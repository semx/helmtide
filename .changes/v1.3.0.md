# v1.3.0

### Fixed

* plan export no longer risks deleting the system temp dir or an unsafe --plandir: the dangerous os.TempDir() fallback is gone and export now validates the symlink-resolved target (rejecting root, top-level, cwd and the temp root, defeating symlink and relative-TMPDIR bypasses) and stages atomically, always keeping the previous plan recoverable if a new export fails partway (@semx)

* guard release plan building against dependency cycles so mutual or self dependencies no longer stack-overflow before the graph cycle detector runs (@semx)

* down no longer hangs forever when an uninstall failure strands a dependant: the WaitGroup now counts only emitted nodes and waits with the context (@semx)

* fix a data race on the monitor-failures map and make failed-monitor remediation deterministic (safer action wins); skip canceled monitor runs (@semx)

* serialize concurrent helm registry logins to prevent credential mixing and shared credentials-store corruption (@semx)

### CI

* ci: nightly self-hosted regression job runs the full integration suite (including the internet-dependent chart suites, HELMTIDE_TEST_REMOTE_CHARTS on) against a long-lived cluster, complementing the hermetic hosted CI (@semx)

* test: skip the fixture-20 Prometheus monitor test unless a Prometheus is reachable at localhost:9090, so the self-hosted regression against a remote cluster no longer fails on a test-host topology assumption (@semx)

### Other

* logs: replace decorative emoji in log and CLI usage strings with clear, informative messages (e.g. "syncing releases", "release deployed", "plan has no changes") for a more professional, greppable output (@semx)
